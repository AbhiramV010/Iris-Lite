Iris-Lite

Perceptual Edge Surveillance Architecture

01 // Architecture

The system utilizes a multi-tiered pipeline executed on a Raspberry Pi 4B. By managing frames entirely within a sliding 5-minute Shared Memory (SHM) buffer, it bypasses continuous disk I/O overhead and avoids premature flash storage cell wear.

Shared Memory Ring

Provides O(1) frame access queries via explicit RAM caching, protecting backing media from continuous raw writes.

Carbon-Aware Governance

Monitors regional grid parameters to transition system dependencies adaptively based on energy footprints.

02 // Event Filtration

Iris-Lite evaluates scene activity through two isolation segments before promoting arrays to full storage commits:

// Dual-Tier Spatial Isolation Pipeline
Tier_1: Always-On Background Subtraction (CNT)
        └── IF Contour Threshold Crossed -> Activate Tier_2
Tier_2: High-Context Motion Entropy Analysis
        └── Verification: Spatial-Temporal Consistency Filter (50-Frame validation)

An on-board LiteRT convolutional network concurrently reviews ambient acoustic waveforms to scan for high-risk acoustic event anomalies (e.g., glass breakage, crashing) above a hard threshold of -21.9 dBFS.

03 // P.E.L.I.C.A.N. Engine

The Perceptual Edge Lightweight Intelligent Compression and Adaptive Network dictates frame prioritization. Instead of processing raw arrays uniformly, it optimizes stream density relative to historical scene context metrics.

[Input Stream] ──> Dual Resolution Matrix (1080p / 320x180)
                       │
                       ├──> Feature Density Extraction (Edge/Motion)
                       └──> Real-time Quantization Control (Dynamic CRF)

When the internal system governor reports elevated thermal or processing strain, quantization thresholds scale to guarantee linear throughput speeds without compromising tracking cohesion during event bursts.
