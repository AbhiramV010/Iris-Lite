Iris‑Lite

The Sustainable Security System — powered by edge computing, multi‑modal detection, and the P.E.L.I.C.A.N. compression engine.

Overview

Iris‑Lite solves the failures of modern cloud‑dependent surveillance:

  • No cloud dependency
  • Event‑driven recording
  • Carbon‑aware charging
  • Multi‑modal detection (audio + vision + zones + GPIO)
  • One‑time hardware cost (~$75 CAD)

Edge Processing

All computation happens on‑device. Zero cloud reliance.

  • zone_monitor.py — GSOC background subtractor
  • listener.py — TF‑Lite CNN audio classifier
  • detector_pipeline.py — Two‑tier filter protocol
  • Compression — Saliency‑centered H.264 engine

Sound Detection

Listener.py captures audio at 16 kHz → Mel spectrogram → CNN.

  • Gunshots
  • Screaming
  • Glass breaking
  • Dog barking
  • Car screeching
  • Aggressive knocking

Two‑Tier Filter Protocol

Tier One

  • Brightness shift detection
  • CNT background subtraction
  • Triggers if >25% non‑zero pixels

Tier Two

  • Shannon entropy
  • Centroid tracking
  • 50‑frame persistence

Zone Monitoring

GSOC + HSV grass segmentation + bottom‑20‑pixel trigger.

Consumes 34–38% CPU on Pi 4B.

P.E.L.I.C.A.N. Compression

Perceptual Event‑Linked Intelligent Compression & Adaptive Networking.

Importance Engine

  • Motion intensity
  • Edge density
  • Temporal context
  • GPIO sensor fusion

Privacy & Scalability

Sustainability
